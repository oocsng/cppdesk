# Security Policy

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 3.5.x   | Yes                |
| < 3.5.0 | No                 |

We strongly recommend always running the latest stable release to receive security enhancements, crypto hardening, and critical protocol updates.

## Reporting a Vulnerability

If you discover a security vulnerability in CppDesk, please report it privately. Do not open public GitHub issues or post publicly on social channels.

### Preferred Channel

Use GitHub Private Vulnerability Reporting:
1. Navigate to the **Security** tab of the CppDesk repository on GitHub.
2. Select **Advisories** and click **Report a vulnerability**.
3. Provide details on the vulnerability, affected components, reproduction steps, and potential impact.

### Alternative Channel

If you cannot use GitHub Security Advisories, send an encrypted or plaintext email to:

`security@cppdesk.io`

Include:
- Type of vulnerability (e.g., buffer overflow, crypto bypass, authentication flaw)
- Affected platforms and versions
- Step-by-step reproduction instructions or a minimal proof of concept
- Potential impact on client or host machines

## Response Timeline

- **Initial acknowledgment**: Within 48 hours of receipt.
- **Triage and assessment**: Within 5 business days.
- **Remediation and disclosure**: We coordinate patches and public advisories within 14 to 30 days depending on severity and coordination requirements.

We appreciate responsible disclosure and will credit researchers in release notes with your consent.
