One file does the whole job.

Everything below ships in the same portable app, on the host and on the viewer.

Every machine in a tab

Tabs

Control several machines at once. Each tab shows a live ping and an unread chat count. An address book with quick tags keeps the list tidy.

Move files

SHA-256

Drag and drop with progress for each file. Folders can mirror both ways in the background. Every file is checked with SHA-256.

Fix things

Terminal

Remote command prompt, PowerShell or bash, and a task manager that can end processes. Ctrl+Shift+P opens a command palette.

Record and rewind

Record

Record a session to an uncompressed AVI file with a built-in player (best for short clips), or scrub back through recent frames without dropping the connection.

Talk and point

Voice

Voice chat, shared clipboard, a shared scratchpad, and pens and pointers to draw on the remote screen.

Pick the quality

fps

15304560

Four presets in frames per second, plus multi-monitor selection and automatic resolution matching.

Forward ports

Ports

One-click presets for RDP, SSH, VNC and the web, plus diagnostics for the connection.

Locked down.

Encrypted end to end

Keys are exchanged with ECDH on NIST P-256, and the session is encrypted with AES-256-GCM.

  • Optional TOTP two-factor (RFC 6238) with QR setup
  • Brute-force rate limiting
  • On Windows hosts, a curtain mode that blanks the host screen
  • On Windows hosts, privacy zones that hide parts of the host screen

Free and open source under the Apache 2.0 licence. Each download is the latest release on GitHub.

x64

Portable. Double-click CppDesk.exe. No installer and no registry changes. Windows 10 or 11, 64-bit.

Linux, any distro

x86_64

The AppImage runs on an X11 desktop. Allow it to run once (chmod +x), then double-click. Wayland screen sharing is experimental.

Download AppImage

amd64
