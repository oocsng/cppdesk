CppDesk is a portable remote desktop app. Machines on the same network connect to each other directly, with a 9-digit ID and a password. One file. Nothing to install.

First connection

  1. On the machine you want to control, note its 9-digit ID and one-time password.
  2. On the other machine, enter the ID and password and press Connect. Leave the password blank to ask the person at the host to approve.

One file does the whole job.

Everything below ships in the same portable app, on the host and on the viewer.

Every machine in a tab

Control several machines at once. Each tab shows a live ping and an unread chat count. An address book with quick tags keeps the list tidy.

Tabs · Ping · Address book

Move files

Drag and drop with progress for each file. Folders can mirror both ways in the background. Every file is checked with SHA-256.

SHA-256 · Two-way sync

Fix things

Remote command prompt, PowerShell or bash, and a task manager that can end processes. Ctrl+K opens a command palette.

Terminal · Tasks

Locked down

Encrypted end to end

Keys are exchanged with ECDH on NIST P-256, and the session is encrypted with AES-256-GCM. Optional TOTP two-factor (RFC 6238) with QR setup, brute-force rate limiting, a curtain mode that blanks the host screen, and privacy zones that hide parts of it.

ECDH P-256 · AES-256-GCM · TOTP

Record and rewind

Record a session to a video file with a built-in player, or scrub back through recent frames without dropping the connection.

Record · Rewind

Talk and point

Voice chat, shared clipboard, a shared scratchpad, and pens and pointers to draw on the remote screen.

Voice · Clipboard · Draw

Pick the quality

15304560

Four presets in frames per second, plus multi-monitor selection and automatic resolution matching.

Quality presets

Forward ports

One-click presets for RDP, SSH, VNC and HTTP, plus diagnostics for the connection.

RDP · SSH · VNC · HTTP

Relay

Optional. STUN and a self-hosted relay can cross networks. You do not need them on one LAN.
